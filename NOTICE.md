# Provenance and publication status

Co-memo is a native Rust CLI and MCP server. Its memory behavior and database format originated in Codey's memory engine. The original engine was covered by the MIT license, whose copyright and permission notice are preserved in [LICENSES/original-engine-MIT.txt](LICENSES/original-engine-MIT.txt). The TypeScript sources and Node.js tooling have been removed. The synthetic JSON compatibility fixture contains no executable TypeScript or real user memories.

The public license for the new work remains undecided. Cargo package publication is disabled (`publish = false`). Public source hosting does not itself grant a license to the new work or supersede the original MIT terms.

Runtime databases, build output, and dependency directories are excluded from version control. No real memories or credentials are included.
