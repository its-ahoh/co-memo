Real memory storage. Simulated agents. No API key needed.

How this demo works

Your note is saved to a separate demo database. Claude Code and Codex are labels here; no live model or extraction service runs. Sharing allows the second agent to retrieve the note on its next query.

This walkthrough shows only the note you create. The library also supports projects, file imports, and review history. Restarting the demo keeps previous notes in the demo library.
